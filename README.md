# 🧮 Python Calculator

## 📌 Project Description
This is a simple calculator project developed using Python. It performs basic mathematical operations such as addition, subtraction, multiplication, and division.

This project is created to practice Python programming fundamentals and improve problem-solving skills.

## 🚀 Features
- Addition (+)
- Subtraction (-)
- Multiplication (*)
- Division (/)
- User input
- Displays calculation results
- Handles division by zero

## 🛠️ Technologies Used
- Python 3
- VS Code / Python IDLE

## 📂 Project Structure

```text
Calculator/
│
├── calculator.py
└── README.md
```

## ▶️ How to Run the Project

1. Download or clone this repository.
2. Open the project folder.
3. Run the following command:

```bash
python calculator.py
```

4. Enter two numbers.
5. Select the mathematical operation.
6. View the result.

## 💻 Sample Output

```text

Enter second number: 5

Select operation:
1. Addition
2. Subtraction
3. Multiplication
4. Division

Enter your choice: 1

Result: 15
```
